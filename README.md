# Task Management API

A secure REST API for managing tasks with user authentication, JWT tokens, and role-based access control. Data is stored in-memory.

---

## Tech Stack

- Node.js
- Express
- bcryptjs
- JSON Web Tokens

---

## Features

- User registration and login
- JWT authentication
- Task CRUD operations
- Users can only manage their own tasks
- Admin access to view all tasks

---

## How to Run

```bash
npm install
npm run dev
```
